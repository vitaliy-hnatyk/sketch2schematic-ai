# Roadmap

## Near term

- Publish a reproducible labeled dataset recipe.
- Train and benchmark a baseline circuit-symbol detector.
- Add component-orientation prediction.
- Improve OCR grouping of reference/value pairs.
- Add manual wire bend editing and stable net IDs.

## Medium term

- Add ERC-style connection validation.
- Add transistor, MOSFET, transformer, relay, op-amp, and connector symbols.
- Export SPICE-compatible netlists.
- Add synthetic training-data generation from the IEC symbol library.
- Add model benchmarking across printed, scanned, colored, and handwritten diagrams.

## Long term

- Multi-page and hierarchical schematics.
- Symbol-library packages and plugin API.
- Collaborative editing.
- Versioned project format and migrations.
