# Supported symbols

## Editor and IEC library

- wire
- junction
- terminal
- resistor
- fuse
- capacitor
- battery
- source
- diode
- zener diode
- LED
- SCR / thyristor
- inductor
- switch
- lamp
- ground

## Detection support

Actual AI detection depends on the classes included in the loaded ONNX model. Heuristic recognition supports a smaller set and is intended as a fallback.
